# How we behave here

This is a small repository run by one person. The rules fit on a page.

**Be plain.** Say what a machine does and what you saw it do. No superlatives, no
marketing, no exclamation marks. If you are guessing, say you are guessing.

**Be patient.** Tristan reads every proposal himself and he does not write code. If
your proposal cannot be understood from its own description, he will ask rather than
guess — and asking takes days sometimes, not minutes.

**No harassment, no abuse, no contempt.** Not toward him, not toward another
contributor, not toward the volunteers who lend graphics cards to the AI Horde.
Disagreeing about a source is fine; being unpleasant about it is not.

**Do not use this repository as a channel for anything else.** No promotion, no
recruiting, no links to services that are not the source you are proposing.

**Do not report security problems in public.** See [SECURITY.md](SECURITY.md).

Anything that breaks the above gets closed, and if it is repeated, blocked. There is
no committee and no appeal: it is one person's repository.
